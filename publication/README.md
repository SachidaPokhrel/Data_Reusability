# Curated evidence and provenance

- `verified_downloads.tsv`: source filenames, sizes, Zenodo download URLs and verified checksums copied from HPC receipts, without local paths.
- `assembly_annotation_sha256.tsv`: checksums recorded by the original pilot for its 19 assembly and gene annotation files and 18 repeat files.
- `software_versions.tsv`: software recorded by the original pilot.
- `pilot_status.json`: biological scope, gate and validation outcome.
- `SHA256SUMS`: checksums for the published evidence and report, relative to the repository root.

The source run’s unmodified logs and receipts are retained in the local HPC copy only. No final end-to-end historical biological audit is claimed.
