# Study design

H1 tests coding-conserved genes for variable upstream DNA. H2 tests repeat associations.
H3 evaluates what gene-centered conservation labels omit. All remain hypotheses until data run.

The strict population is all-19 single-copy core orthogroups. Pilot isolates are six representatives
chosen by reproducible farthest-point sampling on published genotype distances, not by upstream
outcomes. Pilot genes are a seeded random sample after coding/synteny QC and before upstream QC.
An all-19-core flag is distinct from a pilot-six-core flag. Synthetic data have their own label.

Default thresholds are set before viewing real results: coding combined divergence ≤0.01;
conserved upstream ≤0.01; variable upstream ≥0.05; callable fraction ≥0.70 and ≥80% matched
valid pairs. Intermediate upstream divergence remains unresolved. Prespecified sensitivity grids
cover CDS thresholds 0.005/0.01/0.02 and upstream thresholds 0.02/0.05/0.10 for both window sizes.

The prevalence target is explicitly conditional on the strict core and QC design. Report
candidate fraction among high-quality coding-conserved loci, unresolved counts, and bounds
including unresolved coding-conserved loci. The target is not species-wide prevalence. Candidate
illustrations are selected after unbiased prevalence calculations and cannot replace the denominator.

Full mode requires an unchanged-data real pilot gate. An operational gate cannot replace expert
review of homology, annotations and source compatibility.
