# Scientific background

Single-copy core membership describes copy assignment across the sampled isolates. It says
nothing by itself about nucleotide identity. This project evaluates whether coding-conserved
members also have conserved adjacent noncoding sequence, challenging a gene-centered summary
of locus conservation.

Skiadas et al. (2026), [PLOS Biology](https://doi.org/10.1371/journal.pbio.3003596), developed a
19-isolate resource to investigate resistance breaking and genomic/haplotype diversity.
The original graph already represents noncoding variation; this project does not claim to be
the first to observe such variation. Its proposed contribution is a controlled locus-level
contrast and explicit accounting for uncertainty and missingness.

An annotated gene boundary is a provisional coordinate anchor, not a transcription start site.
Upstream DNA is a candidate regulatory neighborhood. Differences require expression or functional
evidence before any regulatory mechanism can be established.
