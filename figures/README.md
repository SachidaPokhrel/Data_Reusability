# Figures

Mode-specific PNG/PDF plots from actual scientific tables. Produced by R figures.R and Python candidate_visualization; consumed by reports and presentation.
Reproduce using the corresponding run.sh command after bootstrap and input mapping.

Raw/large data, alignments and environments are ignored. Small provenance, summary tables,
reports and final figures may be tracked after review. Biological runs use pilot/full subdirectories;
TEST outputs are confined to tests/work. No mock scientific findings are stored here.
